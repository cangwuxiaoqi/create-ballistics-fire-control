# 2.0.1 更新日志

> 用途：CurseForge 上传文件时的 **Changelog**（英文为主），以及群公告 / MC百科 更新日志（中文）。
> 内容范围：**2.0.0 发布之后到 2.0.1 之间的全部源码改动**（已用 `git diff` 核对过）。

---

## English（CurseForge）

```text
2.0.1 — bug fixes and credits

FIXED
- Releasing the Artillery Indicator while hovering in creative flight no longer ends with a
  single-frame FOV pop. Our zoom takeover used the raw FOV option as its base and ignored the
  FOV modifier vanilla applies while flying (x1.1), so the view stayed ~14% narrower than
  vanilla until we handed control back and it snapped wider.
- The held Artillery Indicator no longer pops in scale when the zoom is released. Vanilla
  renders the first-person item with its own FOV pass (GameRenderer#getFov(..., useFOVSetting
  = false), a flat 70 degree base); our zoom was writing the same value to the world pass and
  the hand pass. Each pass now uses its own base.
- Nothing else changed: no gameplay, block, item, recipe or balance changes.

CREDITS / LICENSE
- NOTICE: replaced two dead source links (Superb Warfare and CBC Ballistics repositories)
  with reachable references. No licence terms changed: the mod remains GPL-3.0-only, with
  CBC Ballistics (MIT), Superb Warfare (GPLv3) and GeckoLib (MIT, bundled) credited file by file.
```

## 中文（群公告 / MC百科 更新日志）

```text
2.0.1 —— 两处视野/手感修复与来源链接更新

修复
· 创造飞行、悬停于半空中使用火炮指示器时，松开右键后视野在最后一帧突然变宽的问题。
  原因：接管 FOV 时以「选项里的 FOV」为基准，漏掉了原版在飞行时施加的 ×1.1 修饰，
  于是接管期间画面比原版窄约 14%，放开接管的那一帧又跳回原版值。
· 同一场景下，手持火炮指示器的模型在松手时缩放弹跳一下的问题。
  原因：原版第一人称手持物渲染走的是**另一趟 FOV**（固定 70° 基准），而我们此前对「世界」与
  「手部」两趟写了同一个值；现在两趟各自按自己的基准计算。
· 其余无改动：不涉及玩法、方块、物品、配方与数值平衡。

来源与许可
· NOTICE：更新了两处已失效的来源链接（卓越前线、CBC Ballistics 的仓库地址），改为可访问的地址。
· 许可未变：本模组仍以 GPL-3.0-only 分发；CBC Ballistics（MIT）、卓越前线（GPLv3）、
  GeckoLib（MIT，内嵌分发）的出处与逐文件清单见 jar 内的 NOTICE。
```
