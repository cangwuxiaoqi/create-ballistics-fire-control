## 二、简介（直接粘进「编辑器（简介）」框）

机械动力火炮：火控计算弹道学 是为《机械动力：火炮》（Create Big Cannons）制作的火控系统附属模组，适用于 Minecraft 1.21.1 与 NeoForge 加载器。

模组把火炮的瞄准与击发交给由三个方块组成的火控链路。火控节点 安装时贴住火炮底座任意一面，自动探测这门炮的材质、炮腔格数、炮筒长度、已装填的发射药与弹种，按打击坐标独立解算射击诸元，并用伺服驱动炮塔的俯仰与回旋；火控协调器 把半径 32 格内的火控节点登记为一级炮位，负责把打击坐标下发到每一门炮，并统一下达开火；火控计算机 用于输入打击坐标、选择弹道与火力模式并发出开火指令，一台计算机最多可带 4 台协调器。诸元由每一门炮各自解算，因此不同材质、不同装填的炮混编在同一张火力网里也能各自打准。

解算包含低伸与高抛两条弹道、自动选择弹道（低伸被地形挡住时改走高抛）、弹道遮挡校验与同时弹着的错峰计算。火力模式提供齐射、同时弹着、轮射与范围覆盖四种；装填安全方面，护目镜会给出材质装药上限、炮管与装药的匹配情况、卡弹与炸膛预警以及落点散布提示。

观测与校射由两件物品承担。火炮指示器 举起后可作为观测镜使用，能缩放观察、用中键把目标位置报给火控计算机、长按左键下达开火指令，并可与一台火控计算机绑定；侦测无人机 与 无人机遥控器 配合使用，无人机可飞到目标附近，在无人机视角下完成测距、标记与开火。

弹道物理会跟随整合包环境自动切换：装有「弹道射程优化」时按二次阻力与真实重力解算，未安装时按 Create Big Cannons 原版线性阻力解算。

模组同时支持把火炮架在《机械动力：航空学》（Create Aeronautics）的载具上使用：动平台的提前量会自动计算，并根据实际落点自行修正。落点散布则由炮筒长度与装药量决定（Create Big Cannons 原版机制，模组不修改），界面会给出散布估算，并在炮筒对当前装药太短时预警。

本模组以 GPL-3.0-only 协议分发。

## 三、正文（可放进条目正文或「添加教程」页）

### 三个方块

| 方块 | 作用 | 识别范围 / 上限 | 应力 |
|---|---|---|---|
| **火控计算机** | 输入打击坐标、选择弹道与火力模式、统一开火 | 半径 64 格 / 最多 4 台协调器 | 背面接传动轴，每 1 RPM 消耗 64 SU |
| **火控协调器** | 登记下辖炮位，把目标下发到每一门炮 | 半径 32 格 / 最多 10 门炮（超出时取最近的） | 每 1 RPM 消耗 32 SU |
| **火控节点** | 探测所在那门炮、解算诸元、伺服瞄准与击发 | 1 门炮（挨着炮座任意一面即可） | 每 1 RPM 消耗 8 SU |

链路的连接顺序是 火控计算机 → 火控协调器 → 火控节点 → 火炮。协调器与节点都有转速要求，转速不足时不会工作，游戏内会给出提示。

### 弹道与解算

- **两种弹道模式**：低伸、高抛；另有「自动」，会优先使用低伸，低伸被地形挡住或不在射界内时自动改用高抛。
- **遮挡校验**：对弹道做逐点采样，检查是否会撞到方块；炮口被堵、目标太近、超出射界、仰角压到极限等情况都会给出具体原因。
- **同时弹着**：按每一发炮弹到达目标的时间错峰开火，使多门炮的炮弹同时落地。
- **火力模式**：齐射、同时弹着、轮射（可设间隔）、范围覆盖（可设覆盖半径，把落点按网格铺开）。
- **装填与安全提示**：材质装药上限（熟铁 1 / 铸铁 2 / 青铜 4 / 钢 8 / 下界钢 10 包，实际取「材质、炮闩强度、炮腔格数」三者最小值，速射炮闩一律只装 1 包）、炮管长度与装药量的匹配、卡弹与炸膛风险提示、落点散布估算。

### 航空学载具上的火炮

架在《机械动力：航空学》（Create Aeronautics）的船或飞机上的火炮同样可用。由于射击平台在移动、而 Create Big Cannons 的**炮弹不继承载具速度**，模组会沿平台行进方向自动施加提前量，并根据实际观测到的落点不断修正这个提前量。**「动平台打静止目标」已完整支持。**

该联动不需要任何配置：装有 Create Aeronautics 与 Sable 时自动识别、在运行期接线（**没有包含它们的任何代码或素材**）。

### 关于散布：为什么打不准

散布是 Create Big Cannons **本身的机制，不是火控瞄不准**。一门炮的散布从所装发射药起算（装药越多、起步散布越大），然后**每增加一格炮筒递减一次**，一直减到这门炮材质自身的散布下限为止。因此**炮筒短而装药多时，散布会一直很大** —— 这时即使瞄准完全正确，落点仍会散开。

本模组**不修改该机制**，而是读取 Create Big Cannons 自己的数值，把最终散布估算显示出来（沿射线方向的横向分量与弹道方向的分量），让玩家在开火前就知道大致会散多大；护目镜还会在「炮筒对当前装药太短」时给出预警，并说明**再加几格炮筒**才能压到该材质的散布下限。

因此出现落点散布时，应优先检查**炮筒与装药的搭配**：加长炮筒，或减少装药。火控的作用是把炮瞄准到「这门炮与这份弹药允许的最准」，但改变不了炮与弹药本身的散布。

### 两件物品

- **火炮指示器**：举起时进入观测状态，按住右键缩放、滚轮调节倍率，中键把目标坐标报给已绑定的火控计算机，长按左键下达开火指令；按快捷键可打开设置界面切换模式。把它放在副手时，可配合无人机完成标记与开火。
- **侦测无人机 / 无人机遥控器**：右键放出无人机，潜行空手右键回收；遥控器与无人机绑定后，右键进入无人机视角并直接操控，再右键退出，无人机会原地悬停。无人机带有耐久，撞墙或撞地都会扣除耐久；飞出视距或模拟距离会自爆。

### 使用流程

1. 造好一门炮（炮座 + 炮闩 + 炮腔 + 炮筒），把 **火控节点** 贴在炮座任意一面 —— 放下去时正对玩家的那一面接传动轴。
2. 在节点 32 格内放 **火控协调器**，在协调器 64 格内放 **火控计算机**，三者都接上传动轴并给足转速。
3. 在计算机界面输入打击坐标（格式为 `X Y Z`，**中间那格是高度，不是距离**），选择弹道模式与火力模式。
4. 界面会显示每一门炮的装填状态、初速、射界与解算结果；全部就位后点击开火。
5. 需要观测目标时，用 **火炮指示器** 观察并用中键报点；目标在视距之外时，改用 **侦测无人机** 抵近标记。

### 已知限制

- **载具上的火炮不做遮挡校验**：地形遮挡校验只检查世界中的方块，装配在载具（Create 的 contraption）上的方块不在检查范围内，因此在船上开炮时，模组不会提示炮弹会打到自己船体。
- **目标所在区块未加载时无法校验遮挡**：此时护目镜与界面会注明这一条弹道没有做遮挡校验。
- 炮位与计算机之间依赖区块加载；跨区块使用时请确保相关区块处于加载状态。
